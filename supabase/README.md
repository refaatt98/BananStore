# Supabase — متجر بَنان

المشروع: `bananstore` (`lghfzsjpukizqrxjjggf`)

## الجداول
| الجدول | شو فيه |
| --- | --- |
| `settings` | معلومات المتجر (واتساب، إنستغرام، التوصيل المجاني، سعر التغليف، الشريط العلوي) |
| `categories` | الأقسام |
| `products` | المنتجات (الصور روابط Cloudflare R2) |
| `delivery_zones` | مناطق التوصيل وأسعارها + خيار الاستلام |
| `promo_codes` | أكواد الخصم (نسبة، مبلغ، توصيل مجاني) |
| `orders`, `order_items`, `order_events` | الطلبات وقطعها وسجل تغيير الحالة |
| `gallery` | معرض الأعمال (صور وفيديو) |
| `reviews` | آراء الزبائن (بتظهر بعد الموافقة) |
| `faqs` | الأسئلة الشائعة |
| `custom_requests`, `messages`, `subscribers` | الطلبات الخاصة، رسائل التواصل، النشرة |
| `admins` | حساب الإدارة (أول حساب بيتسجّل بيصير المدير) |

## الحماية
- لوحة الإدارة مفتوحة بدون تسجيل دخول: الدالة `is_admin()` بترجع `true` لكل الناس، يعني أي حدا بيقدر يشوف ويعدّل كل البيانات.
- الطلب بينعمل عن طريق الدالة `place_order`: الأسعار، الخصم، التوصيل والمخزون بينحسبوا بالسيرفر، فما حدا بيقدر يغيّر السعر من المتصفح.
- إلغاء الطلب بيرجّع الكمية للمخزون تلقائياً.

## الرفع
الدالة `functions/media-upload` بتعطي رابط رفع مؤقت على Cloudflare R2 (bucket: `banan`).
الكود الكامل للجداول موجود بلوحة Supabase → Database → Migrations.
